An information request lets you send additional details to an organiser. Open the personal link they sent and keep it private. Choose your language if a language selector is available, and check the response deadline shown on the page.

{/* Available with */}
{/* Let Q-bit do it */}

1. Read the introduction and answer the questions that apply to you. Complete any required answers.
2. Choose **Submit information**. Correct any highlighted answers and submit again if needed.
3. Review the confirmation and the answers shown. If **Update my reply** is available, you can edit and submit your answers again while the request accepts responses.

For example, if a required answer is missing, correct the highlighted field and choose **Submit information** again. Changing language keeps the answers you have entered on the form. If you cancel an edit, the previously saved answers are restored. If a response cannot be saved, read the error and use the offered reload option to check the saved version before trying again. Reloading replaces the answers currently shown with the saved version.

If the link is unavailable or the request has closed, contact the organiser.
