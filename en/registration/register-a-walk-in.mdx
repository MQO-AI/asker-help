Walk-in registration lets staff admit and record attendance for someone arriving at an eligible in-person session.

Before handing over the device, ask an organiser for the session's four-digit staff return code. The participant completes the form, then staff use the code to return to check-in.

## Enable walk-ins

With Registration setup access, open **Settings > Walk-ins**, select the session, and enable **Allow walk-in registration for this session**. Changes save immediately. A return code is generated when walk-ins are first enabled and shown once. Share it privately with check-in staff. **Replace staff return code** creates a new code and invalidates the previous one for everyone checking in that session.

## Hand over the form

1. Open **Check-in & feedback**, select the session, and choose **Register walk-in**.
2. Read the handover warning and choose **I have the code. Open form**. The form hides staff information and locks Asker tabs using that browser login.
3. Give the participant the device. They enter first and last name, optional email, and the displayed privacy and newsletter choices. After submission, the participant returns the device to staff.
4. Enter the staff return code to return to check-in. The walk-in is marked present. No registration confirmation email is sent.

A capacity warning can appear while walk-ins remain allowed. If you do not have the code, cancel before opening the form. If it is unavailable later, ask the organiser to replace it from another authorised device or browser, then use the new code.
