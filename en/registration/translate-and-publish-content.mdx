Translate and publish Registration content to make reviewed form, session, and message wording available in an offered language.

Where the Registration uses published content, save the form and review the publication notice before opening it. **Languages** is also where you review translations and publish content. For example, review the fictional open house's session title and confirmation wording before publishing.

## Publish saved content

1. Save the form and other pending edits.
2. In the publication notice, select **Review pending changes** to inspect the saved changes, when available.
3. Select **Review and publish**, or **Resolve publishing blockers** if that is shown. This opens **Languages**.
4. Resolve the listed items to check before publishing. Save any translation edits.
5. Choose **Publish content**.
6. Check for **Registration content published** and the published revision. The publication notice shows **Saved content matches the published version** when there are no remaining saved changes.

If **Publish content** is unavailable, check for unsaved translation changes, items to check, or an indication that there are no unpublished changes. If publication reports an error, review the message and the published status before retrying.

## Offer another language

Enable **Multilingual support** in **Settings > General**, save settings, and open **Languages** to prepare the content. For example, review the French session titles and confirmation wording alongside the form before offering that language.

1. Review and edit translations that are missing or need review. Select **Offer Canadian French when published**, or the displayed target language, when ready.
2. Choose **Save translations**, then preview the language. Check session labels and messages as well as the form.
3. Follow the publication steps above when the content is ready.

Saving is not publication. The publication notice identifies saved changes that are not live. **Review pending changes** can show the differences between saved and published content. If a detailed comparison is unavailable, review the saved content before publishing. Capacity, bookings, and operational session status take effect separately. Messages already queued or sent keep their wording.

Source-language live preview can include unsaved form changes. Translated preview uses saved translated text with current appearance edits, so save other form changes before checking that language. Supplementary Survey questions have their own language review and publication.

If saving or previewing fails, retry after restoring access. Check the saved version before replacing your work.
