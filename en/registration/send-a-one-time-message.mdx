A one-time message reaches a selected session and booking-status audience without changing the reusable templates.

{/* Available with */}
{/* Let Q-bit do it */}

Staff can send or schedule it from **Messages**. Choose **Compose message** under **One-time message**. For example, prepare a location update for confirmed registrants and review the audience before queueing it.

1. Choose the **Session** and **Audience status**. Enter sender name, reply-to, subject, and body. The sender name is a display name; the email uses the approved Registration sending address.
2. Optionally enter a schedule time. Review the message and send a test to approved addresses. A test uses sample links and does not change the selected audience.
3. Review the selected session, status, and message, then choose **Queue campaign**. The audience is fixed when the campaign is queued.

Open **Delivery history** to filter by session, status, and message type. A queued message is waiting for delivery; it does not prove that a recipient read it.

If the result of sending is not confirmed, use the offered retry for the same operation. Check its result before creating another message to avoid a duplicate.
