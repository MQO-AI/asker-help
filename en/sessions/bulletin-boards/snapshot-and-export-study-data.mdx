A study data snapshot captures a fixed view of submitted Bulletin Board data for review or export. Create it in **Data & analysis** after a flow version has been published.

{/* Available with */}
{/* Let Q-bit do it */}

1. Choose **New data snapshot** and select the **Flow publication**. Set **Include submissions through** and **Snapshot access ends** in the study time zone. The cutoff cannot be in the future; access can end within 365 days.
2. Choose whether to include written answers and other specified text, and whether to include released excerpts and published replies. Both options start unchecked. Include text only when permitted for the research: pseudonyms do not guarantee anonymity.
3. Choose **Review snapshot settings**, check the version, dates, and included text, then choose **Create snapshot**.

For example, select a cutoff after the first week to review submissions received through that time. Review the text options before creating the snapshot, especially if you plan to share an export.

The snapshot includes submitted activities, not unsubmitted drafts or contact details. Select it to review its coverage and download answers as CSV, the codebook or full snapshot as JSON, and discussion as CSV when included. Answers and discussion are separate datasets. Creating a snapshot or downloading it does not run A.I.

If Q-bit analysis is available, choose **Review sources** to inspect the snapshot. Select one snapshot per Board. You can choose to include captured written answers or discussion text only when that text is in the snapshot. Preparing the source does not run A.I.; asking a question sends relevant selected evidence to the A.I. provider.

The contextual Q-bit panel can find snapshots, but cannot read their written answers or discussion text through its lookup. Use the selected snapshot in full Q-bit Analysis for that content.

Snapshot expiry stops access to the snapshot; it does not delete research records or previously downloaded files. If a snapshot is unavailable, check access or create a new snapshot. Q-bit does not select a replacement automatically. If snapshot creation is unconfirmed, retry the same request before creating another.
