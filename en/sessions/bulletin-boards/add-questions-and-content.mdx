Activity questions and content guide what participants read and answer in a Bulletin Board study. Open a study's **Study flow**, select an activity, and add the content and questions participants will see.

## Questions

To add a written question to an activity:

1. Open **Study flow**, choose **Edit flow**, and select the activity.
2. Under **Questions**, choose a written response in **Question format**, then select **Add question**.
3. Enter the **Question wording**, such as “What would make your local park more welcoming?” Add **Question help text** if needed, and select **Required response** if everyone must answer.
4. Choose **Save draft**, then **Preview flow**. Open the activity preview and check the question and instructions.

Other formats include single choice, multiple choice, rating scale, and grids with one or multiple choices per row. For choices and grids, add and label choices or rows. Configure **Other**, exclusive choices, selection limits, and scale endpoints where appropriate.

A later question can be shown when an earlier choice answer matches selected options. Choose **When an earlier response matches**, its source question, and matching choices. The editor can also clear a response when earlier answers change. For example, ask a follow-up only when a person selects the relevant service. Preview both paths. A question or choice used by a condition cannot be removed until the dependency is changed.

## Participant content

Choose a **Content format**, then **Add content** to add text, callouts, or cards before the questions. Text can include bullet points; callouts have an information, benefit, or consideration style. Cards can share labelled fields and compare values. Arrange content in the intended reading order and complete any fields marked as needing attention. An activity can contain up to 30 content blocks.

For example, show a service follow-up only when the participant selects that service, then change the earlier answer in the preview to check both paths and the configured response-clearing behaviour.

Choose **Save draft** and **Preview flow**. Saving does not publish the study.
