A recording delivery gives selected recipients access to a ready Focus Group recording and chosen Studio assets. Authorised staff can open **Results → Recording Studio**, select the segment, and choose **Sharing Centre**.

{/* Let Q-bit do it */}

1. In **New delivery**, select the recording version, enter a delivery label, and review the sender name. The session recording is included. Select any additional ready assets and, if needed, **Include transcript**. When available, **Include clip notes** shares current notes and future edits while access is enabled.
2. Choose **Observers** and select recipients, or choose **External recipient** and enter a name and email.
3. Set **Allow downloads** if needed. Choose an expiry of **7**, **14**, **30**, or **90 days**, or **Never**. Downloads and transcript inclusion are off by default, and the initial expiry is seven days. Recording retention can end before a link expires.
4. Choose **Preview email**. Review the recipients, included assets, expiry, and download setting, then choose the **Create** button showing the number of shares to send the delivery.

For example, use a seven-day delivery with downloads off when recipients need temporary playback access. Review those settings in the email preview before creating the delivery.

Asker sends each recipient one email with access instructions. A first-time recipient sets a password using the setup link, which expires after 48 hours. A returning recipient can use their existing password for recording links shared with them from that Focus Group. In **Shared links**, staff can copy a link, reissue a password link, change the download or transcript setting, change the link expiry or compatible recording version, or revoke access. A password reset applies to that recipient's recording links from the Focus Group. Revocation cannot be undone; create a new share if access is needed again.

An asset's **Copy link** creates or reuses a passwordless public link to the original asset. Anyone with a valid link can open it. A recording version preview does not change the asset. When available, you can also include clip notes. This link is separate from a recipient-specific delivery in Sharing Centre. If a recording or asset is still processing, wait until it is ready. Some recording versions are unavailable with selected Studio assets; choose a compatible ready version. If a recipient needs to reset their password or their setup link has expired, reissue the password link.

Recipient instructions: [Open a shared recording](../../participant-help/focus-groups/open-a-shared-recording).
