Tracking sets maintain shared item labels and variable names for use across surveys.

Use a set when a team needs a consistent coded list, such as the same community services in several survey waves. Coordinate changes with the people using the set, especially when a variable name is already in use.

## Create a set and add items

1. Open **Data & tools** and select **Tracking Sets**, then select **Add tracking set**.
2. Select the new set, enter a **Set name** and optional **Description**, and leave each field to save it.
3. Select **Add item**, edit its label and variable name, and select **Save**. Alternatively, select **Paste items** and enter one item per line as `Item label, VARIABLE_NAME`. Apply the list and check the resulting items.
4. Give each item a unique variable name within the set. Keep variable names stable across surveys.

## Maintain items and subsets

To edit a locked item, select **Unlock**, make the change, and select **Save**. Enter a change log note when prompted and save it. Review the item history when you need to understand an earlier change.

Under **Subsets**, select **Add subset**, name it, leave the name field to save, and select its items. Subsets organise selections for survey-specific use. To remove a subset, select **Remove subset**. See [Link question items to a tracking set](../surveys/tracking-sets-in-questions) for the available question editor controls.

**Archive** removes an item from the active list and its subsets. The archived item reserves its variable name. In **Archived items**, use **Restore** if the variable name does not conflict with an active item. Restoration does not add the item back to subsets automatically, so review those selections. **Delete** removes an archived item; check with your team before deleting shared items. If an item is missing after a paste, check the input and variable names, then add the missing item and verify the list.
