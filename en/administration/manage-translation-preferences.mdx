Shared translation preferences store terminology and reviewed interface messages for reuse across an organisation's studies.

{/* Available with */}
{/* Let Q-bit do it */}

Use these preferences to support consistent wording across studies. You need editing access to a Survey or Registration and its **Languages** area. Review each study's draft after applying defaults, since saving shared preferences does not publish changes to that study.

## Save terminology and messages

1. Open the study's **Languages** area, choose the target language, and expand **Translation preferences and organisation terminology**.
2. Select **Add terminology**. Enter the **Original term**, its translation, and an optional **Usage note**. Add, edit, or remove terms as needed. Both the original and translated terms are required. The library accepts up to 300 terms; each term can be up to 300 characters and a usage note up to 600 characters.
3. To reuse a reviewed interface message from this study, select it and use **Remember selected interface messages**. Only reviewed messages matching the current source can be remembered.
4. Review **Reusable interface messages** and select **Save organisation defaults**. Terminology guides future Q-bit translations; saving defaults does not change published studies.

## Apply defaults to a study

With no items selected, use **Add missing defaults to draft** to add applicable messages that are missing. To replace existing wording deliberately, select the messages first and use **Replace selected translations with defaults**. Added messages are drafts: review them, save the study, and publish its content separately when ready. Existing study wording takes precedence unless selected for replacement.

For example, a team can save a reviewed French interface message as a default, add it to a later study's missing messages, and review that study's draft before publishing. See [Translate a survey](../surveys/translate-a-survey) or [Translate and publish Registration content](../registration/translate-and-publish-content).

The optional **Automatically prepare translations after saved source changes** setting applies to the current study, uses Qokens, and requires review of each proposal. It may be unavailable until configured. If defaults cannot load, select **Retry loading defaults**. If saving fails, use the error guidance and reload shared defaults before retrying.
