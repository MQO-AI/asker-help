Archiving removes completed or paused work from current lists; restoring returns it to a list where you can manage it again. Use these actions when a project, Survey, Registration, Session Group, or session should no longer appear in current work, or when archived work needs attention again. You need permission to archive or restore the item.

Archiving may be blocked by linked activity. Read the confirmation for that specific item before proceeding so you know which items will be affected.

## Archive

1. Find the project, Survey, Registration, Session Group, or session and select **Archive**.
2. Read **What archiving will do** and any items under **Resolve these items first**. Follow the links to resolve blockers before continuing.
3. Select **Check again** if the review needs updating. Once there are no blockers, select **Archive item**.

If the check fails or activity changes while the dialog is open, use **Check again** and review the new effects before retrying.

## Restore

Open the relevant **Archived** list, find the item, select **Restore**, read the resulting state, and select **Restore item**. Restoration does not automatically resume all activity:

- A Survey returns to Current with distribution inactive. Open distribution separately when ready.
- A Registration returns to Current as Closed. It does not reopen or requeue notifications.
- A project returns to Current using its previous status, or Draft if it was archived outside Asker. Linked items, client access, and share links keep their current states.
- A Session Group returns to Draft; its sessions and registrations keep their own states. Read the restore confirmation for an individual session before proceeding.

Check the item and its linked work after restoring, then take any separate action needed to resume activity. For example, restoring a Survey makes it available for editing, but respondents cannot use its link until distribution is activated again.
