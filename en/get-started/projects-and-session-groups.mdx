Projects group related Surveys, Registrations, and sessions so your team can find work for the same client or study in one place. Use a project when work shares a client, study, or team context. You need access to the relevant work and permission to create a project or change an association.

## Find or create a project

1. Open **Projects**. Search by project or client, choose **Current** or **Archived**, and use the sort options to find the project.
2. Open a project to see its related work. Select an item to continue in its own workspace.
3. If **New project** is available, select it, enter a project name, and select **Create project**. Add client, team, and other project details in Portal if needed.

## Associate a Survey or Registration

1. Open the item and find its project association. Select **Associate with a project** or **Change project**.
2. Select an existing current project, create a project if that option is available to you, or choose **No project** when appropriate.
3. Select **Save project** and check the resulting association. Archived or cancelled projects cannot be selected.

A Registration linked to a Session Group inherits that group's project, so its project cannot be changed independently in the Registration. Choose the project when creating the [Session Group](../sessions/focus-groups/create-a-session-group), and check its associated work there. If you need to organise several related sessions, create a Session Group first, then associate the group with the project.

If a control is unavailable, ask an administrator to check your permissions. To remove a project from current work, review [archive and restore](./archive-and-restore-work) first.
