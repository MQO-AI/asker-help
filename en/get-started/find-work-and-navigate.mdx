The Asker Overview brings current Surveys, Registrations, and sessions together so you can find work that needs attention. Use the navigation to open a specific area or start a new item. What you can see depends on your access.

{/* Available with */}
{/* Let Q-bit do it */}

1. Select **Overview** in the navigation. Review live Surveys, open Registrations, and upcoming or live sessions in the relevant cards.
2. Use **Continue working** to return to an item that still needs attention, or open the relevant area from the navigation to find more work.
3. Select **Refresh** to update the Overview cards when activity may have changed.

Use **Projects** when several activities belong to the same client or study. The navigation also takes you to Surveys, Registrations, and Session Groups when available. On a narrow screen, open the navigation menu; on a wide screen, the sidebar and available shortcuts help you move between areas. Use the breadcrumb trail when shown to return to a parent page. Q-bit can be opened from the available navigation or assistant control.

For a new item, start in its area: [create a Survey](../surveys/create-and-find-a-survey), [create a Registration](../registration/create-and-find-a-registration), [create a Session Group](../sessions/focus-groups/create-a-session-group), or [create a Bulletin Board study](../sessions/bulletin-boards/create-a-bulletin-board). If an expected area is missing, see [access and permissions](./understand-access-and-permissions).
