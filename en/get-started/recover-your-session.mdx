Session recovery lets you regain access after sign-in expires without immediately losing work in the original Asker tab. If your session expires while you are working, keep that tab open. It may contain changes that have not yet been saved.

{/* Let Q-bit do it */}

1. Follow the on-screen prompt to sign in or complete security verification in the offered window or tab.
2. Sign in to the same account and organisation that you were using in the original tab.
3. Return to that original tab. Once access is restored, check your work and retry any interrupted save or download.

If the account or organisation is different, return to the original identity before continuing. If a connection problem is shown, restore your connection and retry when prompted. An interrupted action may have completed before the connection was lost, so check the current state before repeating it.

## Resolve a survey draft conflict

If a Survey was saved elsewhere while your tab had unsaved changes, saving pauses until you choose a version. Select **Download my changes** to preserve a copy before deciding. **Use the saved version…** discards this tab's unsaved changes. **Keep my version…** keeps this tab's work, and the next save replaces the changes saved elsewhere. Each choice asks for confirmation. Coordinate with the other editor before choosing. See [Save and collaborate on a survey](../surveys/save-and-collaborate).

If an error page offers **Refresh**, try it after preserving any work you can. A refresh can discard unsaved changes. If the problem continues, record the action and displayed message and contact your administrator or support. Never send passwords or security codes.
