Q-bit outputs are generated tables, charts, and reports that analysts can review, revise, and download.

{/* Available with */}
{/* Let Q-bit do it */}

Open an output in **Outputs** and check its source request, evidence, data version, bases, and interpretation before using it. For example, inspect the population behind a comparison before placing the result in a presentation.

Use the output's revision control to request changes, then compare the original and revised result in **Output history and comparison**. A revision uses the original data and files with the current saved context. Review those inputs in the revision dialog before submitting.

Use **Download** for a supported format: tables can be downloaded as CSV or Excel, charts as SVG or editable Excel, and reports as DOCX. Copy controls offer formats appropriate to the selected output. Open the downloaded file and check labels, bases, and layout before sharing it. If a download fails, retry and check your access to the analysis.

For a recipient-facing snapshot, select the completed material in [share Q-bit findings](./share-qbit-findings).
