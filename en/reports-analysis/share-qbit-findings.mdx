Share selected Q-bit findings as a read-only snapshot or create a separate private copy for continued work in Hub.

Analysts should review the contents and audience before creating either copy. A share link suits a recipient who needs to read selected results; a Hub copy is for further private work and does not sync with Asker.

## Create a read-only link

1. Open the sharing controls in the analysis and select the completed messages and outputs to include.
2. Enter a title and choose an expiry of one, seven, or 30 days. Seven days is the default.
3. Choose **Preview shared content**, review **Recipients will see**, then choose **Create share link**. Anyone with the link can view the selected content until expiry or revocation, so send it only to the intended audience.
4. Use **Share links** to review or revoke a link. A revoked or expired link no longer opens the shared snapshot. Copies already saved by recipients cannot be recalled.

The share is a static snapshot of the selected content. It does not include unselected private context or original reference files. Changes to the conversation do not automatically update an existing share.

## Continue in Hub

You need Hub Chat access and an active organisation Hub setup. Choose **Open in Hub** and review the proposed private copy, including its data, context, and extracted references. Select whether to include completed history where offered, then create the copy and sign in to MQO A.I. Hub with the same account. Eligible inputs include Survey responses and reports, Focus Group transcripts, and selected reference files. A reference-only analysis can also be copied.

The copy is separate and does not sync later source changes or access removal. Original files remain in Asker; enabled references contribute extracted text to the copy.

A Bulletin Board analysis, or an analysis containing a Board capture anywhere in its history, does not offer new public shares or Hub copies, even if you choose another data version or omit completed history. Existing share links remain available for review or revocation. If a control is unavailable, check the source and your access.
