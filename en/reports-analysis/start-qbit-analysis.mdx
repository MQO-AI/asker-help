Prepare Q-bit Analysis inputs to ask questions about research data or supporting files.

{/* Let Q-bit do it */}

Analysts can start from the central Q-bit research picker, a Project, a standard Survey, or a Focus Group. For a Bulletin Board, open **Data & analysis**, select a snapshot, and choose **Review sources**. A Project analysis can combine supported sources. You need access to each source.

Available data can include captured Survey responses, saved Survey reports, ready Focus Group transcript versions, and Bulletin Board snapshots. A Registration or Session Group can provide setup context. Live enrolments, contacts, and bookings are outside that context. A selected reference file can also be used without a captured dataset.

## Choose and prepare data

1. Open **Q-bit A.I. Analysis**, choose the research item, and open the data selector in **Inputs**.
2. Select up to 20 sources and review their versions and options. For survey responses, choose the questions needed. Completed, non-preview, non-deleted responses are the default; in-progress responses and written answers are separate opt-ins.
3. If you want written answers coded, also select the eligible **Questions to code**. Including text alone does not select questions for coding. See [code written answers](./code-written-answers-qbit).
4. Prepare the data. Preparation saves a data version for later questions. Select an existing version to return to the same captured inputs; prepare a new version when the underlying data or selection should change.

Q-bit calculates raw Survey results without weights. To report weighted results, select a saved report prepared with the intended weights and filters. Raw captures do not calculate new weighted estimates or significance tests. Fieldwork outcomes and QA context are separate from the response population. Record Collection child records have a different base from respondents. Review the source before interpreting a result.

A Survey response snapshot can include up to 5,000 responses, 150 selected questions, and 300 answer columns, subject to a 2 MB capture limit. If the selection exceeds a limit, narrow it and prepare the data again.

For a Bulletin Board, select one snapshot per study. Choosing another snapshot for the same Board replaces that selection. You can include captured written answers or discussion text only when that text is in the snapshot. A snapshot that excludes text needs to be replaced with a new snapshot to include it. If a requested snapshot is unavailable, Q-bit does not select a replacement automatically. Return to the Board to check access or create a new snapshot.

## Add context and references

In **Inputs**, save the purpose, research questions, audience, background, and role guidance you need. Applying a saved profile replaces those context fields for review; it does not replace data or files. Add reference files from uploads, Project, or Content Centre, and review extracted text and warnings. Supported uploads include PDF, DOCX, PPTX, XLSX, CSV, TXT, and MD, up to 8 MB each. An analysis can hold 20 reference files; deselected files still count toward that limit. Start a new analysis to add more files when the limit is reached.

Review selected inputs, then [ask Q-bit a question](./ask-qbit-about-data). If preparation fails, close the dialog, review the selection, and retry.
