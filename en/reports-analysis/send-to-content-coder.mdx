Send selected written answers to Content Coder to create a separate Hub copy for coding.

{/* Available with */}
{/* Let Q-bit do it */}

Researchers can send the copy for themselves or eligible colleagues. For example, select only the community-feedback question needed for a coding project, then check the recipients before sending. This transfer is separate from coding written answers inside Q-bit Analysis.

1. Open the survey's **Responses** area and choose **Send open ends to Content Coder**.
2. Enter a **Project name** and select the **Written questions**. All available written questions are initially selected.
3. Completed, non-preview responses are included. Select **Also include responses in progress** if needed. This selection is independent of the Responses table filters.
4. Select eligible active colleagues under **Recipients**, then choose **Send to selected recipients**. The action requires a name, at least one question, and at least one recipient.
5. After the success message, open Content Coder in A.I. Hub and import the item from **Survey transfers**. If the transfer was interrupted, use the offered **Retry same transfer** control.

Only selected written answers and snapshot row numbers are copied. Answers can contain identifying information, so review the recipients and selected questions before sending. The Hub copy is independent and does not sync with later survey edits or deletions.
