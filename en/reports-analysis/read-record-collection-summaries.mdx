A Record Collection summary describes the records respondents provided, including completeness and field values.

Researchers can review these child records in the survey's **Responses** area. Select **Record Collection summary**, or select an individual response to inspect its records and field values. For example, a respondent who lists several services contributes several records, so use the record base for a record-level result and the respondent base for a respondent-level result.

The summary has its own **Response statuses** and **Include preview responses** controls. It starts with complete responses and excludes previews. Search and date filters on the response list do not filter this summary, so check its selection before interpreting the result.

Keep the bases separate: a respondent can provide more than one record, so the number of records need not equal the number of responses. The summary distinguishes active and complete records, missing field values, and choice availability. Use these counts and their displayed bases to identify where data is incomplete before comparing results.

For a full data extract, use the [Complete Record Collection package](./export-responses). Its related files use IDs to connect responses, records, and values. Review both the respondent and record bases before reporting a percentage.
