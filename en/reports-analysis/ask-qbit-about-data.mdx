Ask Q-bit about a prepared data version to explore survey results and inspect the supporting evidence.

{/* Available with */}
{/* Let Q-bit do it */}

Analysts should first [choose and prepare data](./start-qbit-analysis), save any context, and select relevant references. For example, use a prepared response dataset to explore differences by region, then check the base for each comparison before reporting it.

1. Review the data version, context, and reference files shown with the question box. Earlier answers keep the inputs used for those answers. Save or discard any unsaved context changes before asking.
2. Enter a question, or select a quick prompt and edit it. For example, ask for response frequencies by region, and request the base and missing values. A question can contain up to 8,000 characters. Pasted tables become text. If the draft is too long, it is kept so you can shorten it or add a supporting document in **Inputs**.
3. Select **Ask Q-bit**. Progress is shown while the request runs. You can leave the page and return to the saved analysis.
4. Open cited evidence and inspect the source, population, base, calculation, and caveats. Review the answer against the data before using it in a report.

Q-bit can use supported frequencies, comparisons, cross-tabs, and descriptive results for selected data. A prompted comparison is a bounded analysis of those inputs, not a separate cross-tab builder. Q-bit calculates raw Survey results without weights and does not calculate new weighted estimates or significance tests from raw captures. For weighted results, select a saved report prepared with the intended weights and filters. Fieldwork and QA context can inform interpretation, but an indicator alone does not prove a response is fraudulent.

Q-bit uses the selected data, files, and saved context. A request can use up to 20 eligible earlier completed turns, subject to size limits. Earlier answers may be omitted when inputs change or the conversation grows. Check **Inputs used for this answer** when reviewing its basis.

If a request is unconfirmed, use **Retry same request** when offered. If the analysis was interrupted and **Resume saved analysis** is offered, it uses the original request, data, files, and context. If access has changed, return to the research item and check your permissions. See [review and export outputs](./review-qbit-outputs).
