Q-bit analysis conversations keep questions, outputs, and their recorded inputs together so analysts can return to their work.

{/* Available with */}
{/* Let Q-bit do it */}

On the central Q-bit page, open **History** and choose **Analysis** or **Text to Programming**. Search for a conversation and select it to continue. Use the available conversation actions to rename or archive it. From a programming workspace, choose **All Q-bit chats** to open the shared history.

Before asking a new question, review the selected data version, references, and saved context in **Inputs**. A prepared version preserves the captured data; prepare a new version to work with a changed selection or later responses. Earlier answers retain their own input provenance, so inspect **Inputs used for this answer** when comparing results.

If a run is still active, its progress appears in the conversation. You can leave and return. If an interrupted run offers **Resume saved analysis**, resuming uses its original request and inputs. Saved sections remain readable when resuming is unavailable. An analysis has a limit of 100 operations, including captures, imported conversation history, unsuccessful attempts, and resumes. Start a new analysis if you reach that limit.

An unsent question kept in the current tab has not been submitted and can be lost on reload. If the source or access has changed, return to the research item and check access before retrying.
