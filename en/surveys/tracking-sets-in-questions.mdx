## When to use it

Use a tracking set when the same coded list is needed across questions or studies and consistency matters. For example, use a shared list of community services in several survey waves so the team can review the same codes. In the Asker sidebar under **Data & tools**, choose **Tracking Sets** to create or review a set before linking it to a question.

1. Open a supported question and find **Tracking set (options)** or **Tracking set (rows)**.
2. Select **Link to tracking set**, choose the set, and select **Confirm**. Linking replaces the question's existing options or rows and their local item settings.
3. Review the resulting items, labels, variable names, and conditions. The linked list is read-only in the question editor.
4. Save the question and draft, then preview the respondent list and any logic or reports that use its codes.

Use **Refresh** to rebuild the linked options or rows from the latest available version of the set. Refresh clears local item settings such as visibility conditions, hidden status, and endpoint labels. Review conditions and any local behaviour you need before saving and publishing the survey. To restore local item settings, select **Unlink** to make the list independent, then update the items and dependent rules. Keep codes consistent when comparing results across surveys.
