# Asker Help Centre

This repository contains the reviewed pages served at [help.asker.ca](https://help.asker.ca). The source articles, review records, and publication process live in the private Asker product repository.

Changes to published pages arrive through reviewed pull requests. The public repository contains only pages, images approved for publication, and the configuration needed by Mintlify.

The [Help Centre](https://help.asker.ca/en) is the reader-facing version.
